# Politique de confidentialité

_Oreille musicale — dernière mise à jour : 19 novembre 2026_

Oreille musicale est un logiciel libre d'entraînement de l'oreille musicale, sans compte, sans publicité et sans traceur. **Aucune donnée personnelle n'est collectée ni transmise.**

## Ce qui reste sur ton appareil

- **Ta progression** : tes réponses (élément joué, réponse donnée, temps de réponse), les étapes franchies, et tes réglages (notation, objectif quotidien, rappel). Elle est enregistrée uniquement sur ton appareil : dans le stockage du navigateur pour la version web, dans celui de l'application sur Android. Elle ne quitte jamais l'appareil.
- **Le rappel quotidien** (Android, si tu l'actives) est programmé sur le téléphone lui-même ; rien n'est envoyé à un serveur.
- **La sauvegarde** : quand tu exportes ta progression, l'appli crée un fichier que tu enregistres ou partages où tu veux. Elle n'envoie ce fichier nulle part d'elle-même.

## Réseau

- La **version web** est hébergée par GitHub Pages : comme pour tout site, GitHub peut enregistrer des données techniques de connexion (adresse IP, navigateur), selon sa propre [déclaration de confidentialité](https://docs.github.com/fr/site-policy/privacy-policies/github-general-privacy-statement). L'appli elle-même n'envoie aucune donnée.
- L'**application Android** embarque tout ce dont elle a besoin et fonctionne sans connexion.

## Ce que l'appli n'utilise pas

Ni micro, ni caméra, ni position, ni contacts, ni identifiant publicitaire, ni outil de mesure d'audience.

## Supprimer tes données

Désinstalle l'application Android, ou efface les données du site dans les réglages de ton navigateur. Pense à exporter ta progression d'abord si tu veux la garder.

## Contact

Pour toute question : [ouvrir une discussion sur le dépôt du projet](https://github.com/DavidGiangiacomo/oreille-musicale/issues).
