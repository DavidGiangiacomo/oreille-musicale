# Oreille musicale

Application web et Android pour entraîner son oreille musicale : reconnaissance d'intervalles, d'accords, de gammes et de modes, difficulté progressive, suivi de progression et révisions espacées.

Le projet est en phase de conception : voir le [document de conception](docs/DESIGN.md) et les [issues](https://github.com/DavidGiangiacomo/oreille-musicale/issues) pour le plan de réalisation.
